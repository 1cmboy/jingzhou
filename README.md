# 荆楚漆艺 · 楚式漆器髹饰技艺专题页

一个介绍湖北荆州国家级非物质文化遗产「楚式漆器髹饰技艺」的单页网站。

设计取楚漆「玄漆为底、朱金为纹」的视觉语言，包含非遗档案、千年时间轴、髹饰工序、馆藏珍品图集（可点开灯箱）、纪录片、传承人与荆州寻访推荐。

## 打开方式

直接双击 `index.html` 即可浏览（图片均已本地化）。

若希望页内的哔哩哔哩视频稳定播放，建议用本地服务器打开：

```bash
cd jingzhou-lacquer
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

视频来自外站，需联网；若页内播放受限，页面中提供了 B 站原链接。

## 技术

- 纯 HTML + CSS + 原生 JavaScript
- 无框架、无构建、无 npm 依赖
- 响应式布局，支持移动端全屏菜单
- 滚动显现、数字计数、图片灯箱、点击加载视频、轻微视差
- 尊重 `prefers-reduced-motion`
